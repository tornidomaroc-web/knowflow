## The problem

Your documents don't talk back.

You upload a PDF, a contract, a product catalog — and then you have to read it yourself, ctrl+F your way through it, or paste chunks into ChatGPT and hope for the best.

Arabic speakers have it worse. Most AI tools are English-first. Half-baked Arabic support. No RTL. No cultural context.

**KnowFlow fixes this.**

---

## What KnowFlow does

KnowFlow turns any file into a knowledge base your team can chat with — in Arabic or English, with no language switching, no prompt engineering, no setup.

Upload a file → create a knowledge base → ask questions → get answers.

That's it.

---

## Who it's for

- **Gulf businesses** managing contracts, catalogs, or compliance docs in Arabic
- **E-commerce sellers** who need to query product specs, pricing, or supplier terms instantly
- **Teams** tired of reading the same 80-page PDF every time a new hire joins
- **Developers** building Arabic-first AI products who need a working foundation

## Features

| Feature | Details |
|---|---|
| 🧠 Bilingual AI agent | Ask in Arabic or English — answers in the same language |
| 📁 Knowledge bases | Organize files into isolated agents per project or client |
| ⚡ Claude streaming | Real-time answers powered by Claude API |
| 🔐 Auth + usage limits | Supabase auth, per-user quotas, freemium-ready |
| 💳 Pricing + waitlist | Built-in pricing page and waitlist flow |
| 🌐 Full RTL support | Arabic-first UI with proper right-to-left rendering |
